# Neuroot — Animation Guidelines 🌱

Version: v1 Draft  
Project: Neuroot — AI Powered Student Operating System  
Document Type: Animation System & Motion Design Guidelines

---

# 1. Animation Philosophy

Neuroot animations are NOT:

- flashy,
- chaotic,
- gaming-heavy,
- attention-seeking,
- or dopamine-overloaded.

Neuroot animations should feel:

- alive,
- soft,
- emotional,
- calm,
- cozy,
- organic,
- and meaningful.

The goal of motion in Neuroot is:

> reduce stress and create emotional attachment.

Animations should make students feel:

- comfortable,
- emotionally safe,
- motivated,
- relaxed,
- and connected.

---

# 2. Core Motion Principles

# 2.1 Motion Must Have Purpose

Every animation must do one of these:

```txt id="mtn2q1"
Guide Attention
Provide Feedback
Create Emotional Warmth
Reduce Cognitive Load
Enhance Immersion
Make UI Feel Alive
```

If animation does NOT serve a purpose:
→ remove it.

---

# 2.2 Motion Should Feel Natural

Animations should behave like:

- breathing,
- floating,
- drifting,
- soft bouncing,
- gentle swaying.

Avoid:

- robotic movement,
- aggressive bouncing,
- instant snapping,
- mechanical transitions.

---

# 2.3 Motion Should Be Calm

Neuroot is NOT TikTok.

Avoid:
❌ hyperactive motion
❌ over-stimulation
❌ excessive particles
❌ gaming-like chaos

Prefer:
✅ subtle movement
✅ ambient motion
✅ soft transitions
✅ calming loops

---

# 2.4 Emotional Motion Design

Motion should create:

- comfort,
- warmth,
- personality,
- emotional connection.

Especially with:

- Sprout mascot,
- dashboard,
- focus mode,
- emotional states.

---

# 3. Neuroot Motion Identity

Neuroot's motion identity is inspired by:

- breathing
- floating leaves
- gentle wind
- warm ambient environments
- cozy digital spaces
- soft organic movement

The UI should feel:

> alive but peaceful.

# 5. Ambient Motion System

Ambient motion makes Neuroot feel alive.

These animations run subtly in background.

---

# 5.1 Ambient Motion Examples

Examples:

- floating cards,
- breathing glows,
- drifting particles,
- moving gradients,
- Sprout idle movement,
- subtle shadows shifting.

---

# 5.2 Rules

Ambient animations must:

- be extremely subtle,
- use low opacity,
- consume low battery,
- avoid distraction.

---

# 5.3 Recommended Speed

```txt id="4yln6o"
Duration: 4s – 12s loops
Easing: easeInOut
Movement Range: Tiny
```

---

# 6. Interaction Animations

These occur during user actions.

Examples:

- button taps,
- task completion,
- card expansion,
- checkbox selection.

---

# 6.1 Interaction Principles

Interactions should feel:

- responsive,
- satisfying,
- soft,
- tactile.

Avoid:

- aggressive scaling,
- hard snapping,
- oversized movement.

---

# 6.2 Button Press Animation

Recommended:

```txt id="j0rmxv"
Scale: 1 → 0.96
Duration: 120ms
Easing: easeOut
```

Feel:

- soft tactile press.

---

# 6.3 Card Interaction

On tap:

- slight lift,
- shadow enhancement,
- smooth expansion.

Avoid:

- dramatic rotations,
- excessive zoom.

---

# 7. Navigation Animations

Navigation should feel:

- smooth,
- fluid,
- connected.

The app should feel like:

> one continuous emotional space.

---

# 7.1 Screen Transition Style

Preferred:

```txt id="jlwmma"
Fade + Slide
Shared Axis
Soft Scale
```

Avoid:
❌ hard cuts
❌ harsh transitions
❌ flashy page flips

---

# 7.2 Navigation Duration

```txt id="4gmv5j"
Fast: 180ms
Standard: 250ms
Slow: 350ms
```

---

# 7.3 Bottom Navigation

Recommended:

- floating active indicator,
- soft glow,
- icon morphing,
- subtle movement.

---

# 8. Sprout Animation System ⭐ CORE

Sprout is the emotional heart of Neuroot.

Sprout animations must feel:

- adorable,
- emotionally expressive,
- alive,
- comforting.

---

# 8.1 Sprout Animation States

Core States:

```txt id="lgx9qo"
Idle
Happy
Focused
Sleepy
Excited
Worried
Calm
Proud
Burned Out
Studying
```

---

# 8.2 Idle Animation

Sprout should NEVER feel static.

Idle behaviors:

- breathing,
- blinking,
- tiny floating,
- leaf movement,
- looking around.

---

# 8.3 Emotional Reactions

Examples:

## Task Completed

- small bounce,
- smile,
- sparkle effect.

## Long Focus Session

- Sprout studies beside user,
- sleepy blinking after long session.

## Burnout Detection

- slower movement,
- calmer expression,
- comforting gestures.

---

# 8.4 Animation Personality

Sprout should:

- react softly,
- never overreact,
- feel emotionally intelligent.

Avoid:
❌ cartoon chaos
❌ exaggerated reactions
❌ childish hyperactivity

---

# 11. Emotional Animation System

Animations should support emotional states.

---

# 11.1 Burnout State

Motion becomes:

- slower,
- softer,
- calmer.

Effects:

- reduced floating,
- muted gradients,
- slower transitions.

---

# 11.2 Happy/Productive State

Motion becomes:

- brighter,
- slightly more energetic,
- uplifting.

Effects:

- subtle sparkles,
- slightly stronger floating.

---

# 12. Reward Animations

Rewards should feel:

- cozy,
- satisfying,
- emotionally warm.

NOT:

- addictive,
- overstimulating.

---

# 12.1 Reward Types

Examples:

- growing plant,
- glowing streak,
- Sprout excitement,
- gentle confetti,
- floating stars.

---

# 12.2 Reward Timing

Keep rewards:

```txt id="jlwmma"
Under 2 seconds
```

Avoid:

- interruptive celebrations,
- long animations.

---

# 13. Loading Animations

Loading states should:

- reduce perceived waiting,
- maintain emotional warmth.

---

# 13.1 Preferred Loading Styles

Examples:

- Sprout reading book,
- floating leaf loader,
- breathing circles,
- growing plant.

Avoid:
❌ generic spinners

---

# 13.2 Skeleton Screens

Use:

- soft shimmer,
- rounded placeholders,
- lightweight gradients.

---

# 14. Notification Animations

Notifications should:

- feel gentle,
- not stressful.

Use:

- soft slide,
- fade in,
- subtle icon animation.

Avoid:
❌ shaking
❌ aggressive vibration
❌ flashing colors

# 15. Empty State Animations

Empty states should feel:

- hopeful,
- cozy,
- calm.

Examples:

- Sprout watering tiny plant,
- drifting clouds,
- rainy window scene.

---

# 16. Animation Timing System

# Standard Timing

```txt id="jlwmma"
Micro: 100–150ms
Fast: 180–220ms
Normal: 250–320ms
Slow: 400–600ms
Ambient: 4s–12s loops
```

---

# 17. Easing Curves

Recommended:

```txt id="jlwmma"
easeOutCubic
easeInOut
easeOutQuart
springSoft
```

Avoid:
❌ linear motion
❌ harsh elastic effects

---

# 18. Motion Accessibility

Neuroot must support:

- reduced motion mode,
- animation scaling,
- accessibility settings.

When reduced motion enabled:

- remove floating,
- simplify transitions,
- reduce particles.

---

# 19. Battery & Performance Rules

Animations must:

- stay performant,
- avoid excessive rebuilds,
- minimize GPU load.

---

# Performance Targets

```txt id="jlwmma"
60 FPS minimum
No frame drops
Low battery impact
```

---

# 20. Rive Animation Guidelines

Rive is CORE to Neuroot.

Use Rive for:

- Sprout states,
- onboarding,
- focus mode,
- emotional reactions,
- dynamic UI components.

---

# 20.1 Rive State Machines

Recommended Structure:

```txt id="jlwmma"
Mood State
↓
Animation Controller
↓
Interaction Triggers
↓
UI Reactions
```

---

# 20.2 Rive Optimization

Rules:

- minimize artboard complexity,
- reuse animations,
- reduce unnecessary bones,
- optimize vector layers.
