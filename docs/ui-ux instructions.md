# Neuroot — UI/UX Design Instructions 🌱

Version: v1 Draft  
Project: Neuroot1 — AI Powered Student Operating System  
Document Type: UI/UX Design System & Experience Guidelines

---

# 1. Neuroot UI/UX Philosophy

Neuroot is NOT a corporate productivity app.

Neuroot should feel:

- alive,
- cozy,
- emotionally intelligent,
- soft,
- calm,
- aesthetic,
- modern,
- playful,
- and deeply human.

The experience should feel like:

> "A caring study companion helping students survive college life."

Users should NEVER feel:

- stressed,
- overwhelmed,
- guilty,
- pressured,
- or emotionally attacked.

Every design decision must support:

- calmness,
- clarity,
- emotional safety,
- and motivation.

---

# 2. Core Design Principles

# 2.1 Cozy Productivity

Neuroot follows the:

> "Cozy Productivity" design philosophy.

This means:

- soft visuals,
- warm interactions,
- low-pressure experiences,
- rewarding microinteractions,
- calming interfaces.

The app should feel:

- emotionally warm,
- soft like a notebook,
- aesthetic like Pinterest,
- smooth like iOS,
- expressive like Duolingo,
- calm like Finch.

---

# 2.2 Minimal Cognitive Load

Students are already overwhelmed.

UI should:

- reduce thinking,
- reduce clutter,
- reduce choices,
- reduce stress.

Avoid:

- huge dashboards,
- information overload,
- giant tables,
- dense menus,
- complex settings.

Every screen should answer:

> "What does the student need RIGHT NOW?"

---

# 2.3 One Primary Focus Per Screen

Every screen must have:

- ONE clear purpose,
- ONE main action,
- ONE emotional goal.

Example:

- Focus screen → immersion
- Dashboard → clarity
- Exam mode → urgency without panic
- Emotional check-in → comfort

---

# 2.4 Emotionally Safe UX

Neuroot NEVER punishes users emotionally.

Avoid:
❌ "You're behind!"
❌ "Missed again?"
❌ aggressive red warnings
❌ guilt notifications

Use:
✅ "Let's reset gently 🌱"
✅ "Small progress still matters."
✅ "You can still recover this week."

The app behaves like:

- a supportive friend,
- not a strict teacher.

---

# 2.5 Dynamic Living UI

Neuroot's UI changes based on:

- exams,
- burnout,
- stress,
- focus,
- time,
- semester progress,
- productivity state.

The app should feel ALIVE.

Examples:

- rainy weather → cozy atmosphere
- exams → sharper focused dashboard
- late night → darker softer UI
- burnout → calmer colors and reduced clutter

This adaptive system is one of Neuroot's biggest differentiators.

---

# 3. Visual Identity

# 3.1 Design Style

Primary Style:

- Soft Minimalism
- Cozy Glassmorphism
- Modern Gen Z
- Emotional Interfaces
- Rounded UI

Secondary Style:

- Playful Companion Design
- Calm Productivity
- Nature-inspired visuals

---

# 3.2 Shape Language

Neuroot uses:

- rounded corners,
- soft containers,
- pill buttons,
- circular cards,
- floating elements.

Avoid:

- sharp corners,
- rigid layouts,
- heavy borders,
- aggressive geometric shapes.

Recommended Border Radius:

```txt id="4v7kpa"
Small: 12px
Medium: 20px
Large: 28px
Cards: 24px
Bottom Sheets: 32px
```

---

# 3.3 Shadows & Depth

Use:

- soft shadows,
- layered depth,
- glowing highlights,
- floating cards.

Avoid:

- harsh shadows,
- hard neumorphism,
- overly realistic depth.

Neuroot should feel:

- airy,
- breathable,
- lightweight.

---

# 3.4 Glassmorphism Usage

Use glassmorphism lightly.

Recommended:

- dashboard cards,
- widgets,
- focus timer overlays,
- bottom navigation blur.

Avoid:

- overusing blur everywhere.

Goal:

> soft futuristic calmness.

---

Colors should feel:

- natural,

# 6. Mascot UX — "Sprout" 🌱

Sprout is CORE to Neuroot's identity.

Sprout should:

- feel alive,
- emotionally expressive,
- reactive,
- comforting.

---

# 6.1 Sprout Emotional States

States:

- happy,
- sleepy,
- focused,
- excited,
- proud,
- worried,
- overwhelmed,
- calm.

Sprout reacts to:

- focus sessions,
- attendance,
- emotional check-ins,
- missed tasks,
- exams,
- productivity patterns.

---

# 6.2 Sprout Interaction Rules

Sprout should:

- encourage gently,
- celebrate softly,
- never shame users.

Example:
❌ "Why didn't you study?"
✅ "Today was hard. Let's try a small step 🌱"

---

# 6.3 Sprout Animation Philosophy

Animations should feel:

- tiny,
- smooth,
- natural,
- subtle.

Avoid:

- hyperactive movement,
- flashy effects,
- gaming-level chaos.

---

# 7. Dashboard UX Rules

# 7.1 Dashboard Purpose

The dashboard should answer:

> "What matters today?"

NOT:

> "Show everything possible."

---

# 7.2 Dashboard Layout

Recommended Sections:

1. Greeting + Sprout
2. Today's Classes
3. Top 3 Priorities
4. Focus Progress
5. Upcoming Exams
6. Attendance Alerts
7. Emotional Status

Everything else should be secondary.

---

# 7.3 Dashboard Feel

The dashboard should feel:

- calm,
- organized,
- motivating,
- breathable.

Use:

- spacing,
- card separation,
- visual hierarchy,
- soft gradients.

---

# 8. Focus Mode UX

Focus Mode should feel:

- immersive,
- peaceful,
- distraction-free.

---

# 8.1 Focus Session Experience

Features:

- fullscreen timer,
- ambient background,
- breathing animations,
- soft soundscapes,
- Sprout studying beside user.

No clutter allowed.

---

# 8.2 Focus Rewards

Reward system:

- growing plant,
- calming particles,
- tiny celebrations,
- streak glow.

Avoid:

- casino dopamine mechanics,
- flashy rewards.

---

# 9. Motion Design System

# 9.1 Motion Philosophy

Motion should:

- guide attention,
- provide comfort,
- feel organic.

Avoid:

- excessive bouncing,
- random flashy animations,
- chaotic transitions.

---

# 9.2 Animation Style

Preferred:

- smooth fades,
- scale transitions,
- soft slides,
- floating movement,
- breathing effects.

Duration:

```txt id="1ykx4w"
Fast: 150ms
Medium: 250ms
Slow: 400ms
```

Easing:

```txt id="6r8y0d"
easeOutCubic
easeInOut
springSoft
```

---

# 10. Notification UX

Notifications must feel:

- calm,
- supportive,
- intelligent.

---

# 10.1 Notification Tone

Use:
✅ "You still have time 🌱"
✅ "One small session today can help."

Avoid:
❌ "Deadline approaching!"
❌ "You're falling behind!"

---

# 10.2 Notification Frequency

Neuroot should NEVER spam.

Rules:

- group notifications,
- context-aware reminders,
- emotional timing awareness,
- silence during stress overload.

---

# 11. AI UX Guidelines

# 11.1 AI Personality

Neuroot AI should feel:

- smart,
- calm,
- supportive,
- emotionally aware.

NOT:

- robotic,
- overly formal,
- overly motivational,
- productivity-toxic.

---

# 11.2 AI Message Style

Examples:
❌ "Optimize your workflow."
✅ "Let's make today easier."

❌ "Increase efficiency."
✅ "Let's reduce the overwhelm."

---

# 11.3 AI Planning UX

AI outputs should:

- feel simple,
- visually structured,
- digestible.

Use:

- microtasks,
- sections,
- progress indicators,
- lightweight plans.

Avoid:

- giant walls of text.

---

# 12. Empty State Design

Empty states should feel:

- cozy,
- motivating,
- hopeful.

Examples:

- Sprout sitting with books
- Rainy window illustration
- Tiny growing plant

Use supportive copy:

> "A fresh start begins here 🌱"

---

# 13. Error UX

Errors should feel:

- human,
- calm,
- non-technical.

Example:
❌ "Synchronization failed."
✅ "Couldn't sync right now. We'll retry soon 🌱"

---

# 14. Onboarding UX

# 14.1 Onboarding Philosophy

Neuroot onboarding should feel:

- warm,
- conversational,
- exciting,
- emotionally safe.

Avoid:

- giant forms,
- overwhelming setup,
- asking too much initially.

---

# 14.2 First-Time User Flow

Recommended:

1. Welcome
2. Meet Sprout
3. Semester Setup
4. Subjects
5. Goals
6. Emotional Preference
7. Dashboard Preview

Total setup time:

```txt id="t92qk7"
Under 3 minutes
```

---

# 15. Accessibility Guidelines

Neuroot must support:

- readable typography,
- high contrast mode,
- reduced motion mode,
- screen readers,
- colorblind-friendly indicators.

Never rely only on color.

---

# 16. Widget Design Philosophy

Widgets should:

- feel alive,
- useful,
- glanceable,
- emotional.

Widgets must prioritize:

- clarity,
- simplicity,
- aesthetics.

---

# 17. Emotional UX Rules

Every screen should ask:

> "How will this make the student feel?"

If stressful:
→ redesign it.

If overwhelming:
→ simplify it.

If emotionally cold:
→ warm it up.

---

Main inspirations:

# 19. Final UX Goal

Neuroot should feel like:

- a study companion,
- a calm digital space,
- a supportive senior,
- a safe productivity environment.

Users should WANT to open Neuroot.

Not feel forced to.

---

# 20. Final Design Mantra

> "Design for overwhelmed students, not productivity machines."

Every interaction should help students:

- breathe easier,
- feel calmer,
- stay organized,
- and grow consistently.

Neuroot is not about maximizing output.

Neuroot is about helping students survive and Neuroot 🌱
