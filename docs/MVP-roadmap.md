# Neuroot — MVP Roadmap 🌱

Version: v1 Draft  
Project: Neuroot — AI Powered Student Operating System  
Document Type: MVP Development Roadmap  
Development Style: Indie Startup / Solo Founder Friendly

---

# 1. Roadmap Philosophy

Neuroot is a BIG vision.

But the MVP must stay:

- focused,
- lightweight,
- emotionally polished,
- technically manageable,
- and launchable fast.

The goal is NOT:
❌ build every feature.

The goal IS:
✅ build the SMALLEST version that feels magical.

---

# 2. Core MVP Strategy

Neuroot wins because of:

- emotional UX,
- adaptive UI,
- attendance intelligence,
- AI planning,
- cozy experience.

NOT because of:

- 1000 features,
- complex dashboards,
- huge infrastructure.

The MVP should prove:

> "Students emotionally connect with Neuroot and use it daily."

---

# 3. MVP Success Criteria

The MVP is successful if users:

- open Neuroot daily,
- track attendance consistently,
- use focus mode regularly,
- emotionally connect with Sprout,
- use AI planner repeatedly,
- and feel less overwhelmed.

---

# 4. What NOT To Build Initially ❌

Do NOT build in MVP:

- social feed,
- chat systems,
- collaborative rooms,
- marketplace,
- desktop apps,
- LMS integrations,
- advanced AI memory,
- voice assistant,
- note-taking app,
- flashcards,
- huge gamification system,
- complex analytics.

These can destroy focus and delay launch.

# 17. Solo Founder Advice

As an indie founder:

- focus on emotional quality,
- not feature quantity.

Neuroot's superpower is:

- emotional connection,
- cozy UX,
- and student understanding.

Even a SMALL Neuroot MVP can stand out massively if:

- animations feel alive,
- dashboard feels calming,
- AI is useful,
- attendance system is excellent.
